# IGN-SilexVSguralp-comparison
Herramienta en Python para la comparación automatizada de sensores sísmicos Silex frente al sensor patrón Guralp CMG-5T, desarrollada en el Instituto Geográfico Nacional (IGN). Genera informes PDF con análisis de señales en tres componentes (Z, N, E) mediante alineación temporal por correlación cruzada de envolventes.
